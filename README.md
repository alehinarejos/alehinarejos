## 👨‍💻 Sobre Mí

Desarrollador de software con una sólida base técnica gracias a mi **doble titulación oficial en Desarrollo de Aplicaciones Multiplataforma (DAM) y Desarrollo de Aplicaciones Web (DAW)**. Cuento con **más de 2 años de experiencia en front-end** y **más de 1 año en back-end**, con trayectoria profesional en empresa optimizando plataformas digitales y acelerando ciclos de entrega.

- 🚀 **Especializado en:** Arquitecturas web modernas con **React 19, Next.js y TypeScript**, ecosistemas **Node.js / REST APIs** y desarrollo nativo en **iOS (Swift / SwiftUI)**.
- ⚡ **Experiencia comprobada:** Reducción de hasta un **20% en tiempos de carga** y optimización del **30% en tiempos de entrega de productos digitales** mediante componentización modular y automatización.
- 🎯 **Filosofía:** Código limpio, arquitecturas desacopladas, cálculos con precisión aritmética estricta y experiencias de usuario fluidas a 60 FPS.
- 📍 **Ubicación:** Valencia, España *(Disponibilidad inmediata, carné B y vehículo propio)*.
